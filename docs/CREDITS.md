# Asset Credits & Licensing

All visual assets and software dependencies distributed in the WanderWheels repository comply with open-source and license-safe distribution standards.

## 1. Vehicle Placeholder Assets
- **Location:** `carrental-api/seed-assets/vehicles/`
- **Origin:** Programmatically generated by `scripts/generate-placeholder-images.cjs` specifically for WanderWheels demo and local development.
- **License:** MIT License (Copyright © WanderWheels Contributors). Free for personal, educational, and commercial development use.
- **Specification:** 800x500 valid PNG raster graphics generated using Node.js standard libraries (`zlib`, `buffer`), featuring geometric luxury fleet styling and custom colorways.
