This document provides a complete audit, classification, and provenance record of all non-code visual assets, stylesheets, fonts, and seed texts in the WanderWheels project.

All assets are classified into three strict tiers:
- **Class A:** Created specifically for this project (or by project contributors).

## 3. Class C: Legacy Theme CSS (Origin Unknown, Earmarked for UI Redesign)

> [!WARNING]
> **Repository Visibility Requirement:**
> The legacy theme CSS files described below originate from an unverified legacy HTML template (`CarForYou - Responsive Car Dealer HTML5 Template`, Author: `WMD Team`, Version 1.0) and an unverified admin dashboard stylesheet.
> **The repository should remain PRIVATE until a comprehensive UI redesign replaces these legacy stylesheets.**

### `carrental-web/public/assets/css/style.css` (Removed)

All legacy Class-C template stylesheets (`style.css`, `bootstrap.min.css`, `owl.carousel.css`, `owl.transitions.css`, `slick.css`, `bootstrap-slider.min.css`, `font-awesome.min.css`) and Bootstrap/jQuery JS packages have been removed from `carrental-web` and replaced with Tailwind CSS v4, self-hosted `@fontsource` fonts, and pure React components.

### `carrental-admin/public/css/style.css` (Removed)

All legacy Bootstrap 3, jQuery, Font Awesome 4.7, DataTables, and template stylesheets in `carrental-admin/public/css/` and `carrental-admin/public/fonts/` have been removed and replaced with Tailwind CSS v4, self-hosted `@fontsource/plus-jakarta-sans`, `@fortawesome/fontawesome-free`, `lucide-react`, and `chart.js`.
